# Историческая шкала России (Django)

Интерактивная хронология военных конфликтов Российской империи 1722–1918 годов — переработка исходного статического сайта ([simple-sit](https://github.com/AlexanderVechkasov/simple-sit)) на Django с полноценной админкой, поиском, обратной связью и защитой на уровне продакшена.

- **Рабочий сайт:** https://alexks09.pythonanywhere.com
- **Исходная статическая версия:** https://github.com/AlexanderVechkasov/simple-sit

## Возможности

- **Шкала событий по векам** — аккордеон карточек с краткой справкой, превью изображений, переходом к полной статье и навигацией «Предыдущее / Следующее».
- **Поиск событий** — модальный живой поиск из шапки и отдельная страница `/search/` (работает без JS), регистронезависимая кириллица и `ё → е`, кнопка очистки поля и сортировка от поздних лет к ранним.
- **Галерея и обработка изображений** — полноэкранный просмотр на `<dialog>` с управлением с клавиатуры; загружаемые в админке большие фото автоматически сжимаются и поворачиваются по EXIF (Pillow), а при удалении записи файлы очищаются с диска (`django-cleanup`).
- **Светлая и тёмная тема** — без мелькания при загрузке (FOUC), с синхронизацией выбора между сайтом и админкой.
- **Обратная связь и 152-ФЗ** — модальное окно и отдельная страница `/feedback/`, скрытое поле-ловушка (*honeypot*), ограничение частоты отправки (rate-limit с поддержкой `X-Real-IP` / `X-Forwarded-For` за прокси) и страница согласия на обработку персональных данных `/privacy/`.
- **Админ-панель (`django-unfold`)** — дашборд «Сводка» со статистикой, просмотр сообщений в модальном окне, live-опрос новых сообщений, верхняя панель массовых действий, подтверждение удаления в `<dialog>`, поиск по кириллице и переведённый интерфейс.
- **Безопасность** — очистка HTML статей по белому списку (`nh3`), нестандартный URL админки через `.env`, раздельные настройки `dev` / `prod`, HTTPS/HSTS/безопасные куки (`manage.py check --deploy` без предупреждений).
- **Импорт со старого сайта** — идемпотентная management-команда `import_events` для переноса событий и картинок из `js/data.js`.

## Стек

- **Python** 3.13+ (разработка на 3.14, деплой на 3.13)
- **Django** 6.1
- **Админка:** `django-unfold`
- **Безопасность и медиа:** `nh3`, `Pillow`, `django-cleanup`
- **Конфигурация и статика:** `django-environ`, `WhiteNoise`
- **Инструменты разработки:** `uv`, `Ruff`
- **База данных:** SQLite по умолчанию (поддерживается переключение на PostgreSQL/MySQL через `DATABASE_URL`)

## Локальный запуск

Требуется установленный [uv](https://docs.astral.sh/uv/) и Python 3.13+.

```bash
git clone https://github.com/AlexanderVechkasov/simple-sit-django.git
cd simple-sit-django
uv sync
```

Создайте `.env` на основе `.env.example` и заполните минимальные значения для разработки:

```bash
cp .env.example .env
uv run python -c "import secrets; print(secrets.token_urlsafe(50))"
```

```dotenv
SECRET_KEY=<сгенерированный-ключ>
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1
ADMIN_URL=panel/
```

Примените миграции, создайте администратора и запустите сервер:

```bash
uv run python manage.py migrate
uv run python manage.py createsuperuser
uv run python manage.py runserver
```

При необходимости можно импортировать события из папки исходного статического сайта:

```bash
uv run python manage.py import_events ../simple-sit
```

## Проверки и тесты

В проекте 55 автоматических тестов (модели, формы, поиск, вьюхи, админка, права доступа, очистка HTML, сжатие картинок, импорт и rate-limit).

```bash
uv run python manage.py check
uv run python manage.py test
uv run ruff check .
```

Проверка боевых настроек безопасности:

```bash
DJANGO_SETTINGS_MODULE=config.settings.prod uv run python manage.py check --deploy
```
